## ✨ معرفی افزونه

**پرگار** یک افزونه وردپرسی قدرتمند و سبک است که با هدف ساده‌سازی فرآیند صدور **فاکتور** و **پیش‌فاکتور** برای فروشگاه‌های ووکامرس طراحی شده است. با پشتیبانی از **المنتور** و **داینامیک تگ‌ها**، شما می‌توانید بدون نیاز به دانش برنامه‌نویسی، طرح‌های کاملاً اختصاصی و مطابق با هویت برند خود بسازید.

## 📦 نصب و راه‌اندازی

### پیش‌نیازها
- WordPress نسخه‌ی **5.8** یا بالاتر
- WooCommerce نسخه‌ی **5.0** یا بالاتر
- PHP نسخه‌ی **7.4** یا بالاتر
- (اختیاری) افزونه‌ی **Elementor** برای طراحی سفارشی

### مراحل نصب

1. فایل افزونه را دانلود کنید.
2. از پنل مدیریت وردپرس به مسیر **افزونه‌ها → افزودن → بارگذاری افزونه** بروید.
3. فایل `.zip` را انتخاب و روی **نصب** کلیک کنید.
4. پس از نصب، روی **فعال‌سازی** کلیک کنید.
5. از منوی **پرگار** در پنل مدیریت، تنظیمات اولیه را انجام دهید.

---

## 🛠️ نحوه‌ی استفاده

```
1️⃣  ورود به پنل مدیریت وردپرس
2️⃣  منوی «پرگار» → «قالب‌ها» → انتخاب یا ساخت قالب جدید
3️⃣  طراحی فاکتور با المنتور یا استفاده از تمپلیت آماده
4️⃣  درج داینامیک تگ‌ها در محل‌های مورد نظر
5️⃣  اتصال قالب به سفارشات و صدور فاکتور
```

### نمونه داینامیک تگ‌ها

| تگ | توضیح |
|---|---|
| `{{order_id}}` | شماره سفارش |
| `{{customer_name}}` | نام مشتری |
| `{{order_date}}` | تاریخ سفارش |
| `{{total_price}}` | مبلغ کل |
| `{{items_list}}` | لیست محصولات |

> ⚠️ تگ‌های دقیق ممکن است بر اساس نسخه‌ی افزونه متفاوت باشند.
